# Return & Cancellation Policy
- Shipped orders cannot be cancelled via self-service; return after receipt is required.
- Orders in 'preparing' state may be cancelled if explicit customer confirmation is provided.
- Already-cancelled orders cannot be cancelled again; no further action is taken.

# 返品・キャンセルポリシー
- 出荷済みの注文はセルフサービスでキャンセルできません。受け取り後に返品手続きをしてください。
- 準備中の注文は、お客様の明示的な確認があればキャンセルできます。
